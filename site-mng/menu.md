# Site Navigation Menu

This file defines the navigation menu structure for the tiMaxal Hub website.
Edit this file to update the site menu, then run `node menu-builder.js` to regenerate `site-nav.js`.

## Format Guidelines
- Use `##` for section headers (will create category headers in menu)
- Use `- [Link Text](path/to/file.html)` for internal links
- Use `- [Link Text](https://url.com) {external}` for external links (opens in new tab)
- Use `  - [Sub Link](path)` (2 spaces indent) for sub-menu items
