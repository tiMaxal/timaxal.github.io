# Quick Reference Card 📝

## 🚀 Quick Updates

### Add a New Page
1. Copy `site-mng/template.html` and rename it in `HTML/` folder (or subfolder)
2. Edit the content (look for ✏️ comments)
3. Adjust file paths based on depth:
   - Depth 1: `../site-helpers/` (e.g., HTML/page.html)
   - Depth 2: `../../site-helpers/` (e.g., HTML/folder/page.html)
   - Depth 3: `../../../site-helpers/` (e.g., HTML/folder/subfolder/page.html)
4. Add to `site-helpers/md/menu.md` with `HTML/` prefix (if it should appear in navigation)
5. Add to `site-helpers/md/site.md` with `HTML/` prefix (to include in sitemap)
6. Run: `site-mng/build-site.bat` (or both builder scripts)

### Update Menu
1. Open `site-helpers/md/menu.md`
2. Edit the text
3. Run: `cd site-mng; node menu-builder.js`
   (This rebuilds both site-nav.js AND footer-loader.js)

### Update Sitemap  
1. Open `site-helpers/md/site.md`
2. Edit the text
3. Run: `cd site-mng; node sitemap-builder.js`

### Update Both
Double-click: `site-mng/build-site.bat`
OR run: `cd site-mng; node menu-builder.js; node sitemap-builder.js`

---

## 📄 Menu Format (menu.md)

```markdown
## Section Name

- [Link Text](./path/to/page.html)
  Optional description

- [External Link](https://url.com) {external}
  
  - [Sub Item](./path.html)
    (use 2 spaces for indent)

### Sub-Section Name
(Creates a nested group within a section)

- [Link](./path.html)
  Description
```

---

## 🗺️ Sitemap Format (site.md)

```markdown
### Section Name
- [Page Title](./path/to/page.html) | 0.8 | weekly

Priority: 0.0-1.0 (higher = more important)
Frequency: daily, weekly, monthly, yearly
```

## 🔍 File Paths

**Correct (in menu.md & site.md):**
- `./HTML/aboutlife/page.html` ✅
- `./HTML/varhns/fotografi/page.html` ✅
- `./HTML/varhns/FishingHowTo/page.html` ✅ (depth 3)

**Wrong:**
- `/HTML/folder/page.html` ❌ (missing dot)
- `HTML/page.html` ❌ (missing ./)
- `./aboutlife/page.html` ❌ (missing HTML/)
- `E:/folder/page.html` ❌ (absolute path)

## 📂 Don't Edit These Files

These are auto-generated by menu-builder.js and sitemap-builder.js:
- `site-helpers/site-nav.js` (from menu.md)
- `site-helpers/footer-loader.js` (from menu.md)
- `site-helpers/sitemap.xml` (from site.md)
- `site-helpers/site-map.html` (from site.md)

Note: The builders automatically detect pages up to 3 levels deep in HTML/ directory

---

## ✏️ DO Edit These Files

Source files (in `/site-mng/`):
- `menu.md` → controls navigation menu
- `site.md` → controls sitemap
