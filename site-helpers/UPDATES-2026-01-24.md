## ✅ Issues Fixed

### 1. HTML Path Duplication (file:///...HTML/HTML/...)

**Problem:** Navigation links were doubling the /HTML/ path when navigating between pages.

**Root Cause:** menu.md had paths starting with `./HTML/` which caused duplication when combined with the prefix logic.

**Fix:** 
- Removed `./` prefix from all paths in menu.md
- Changed `./HTML/software/software.html` → `HTML/software/software.html`
- Regenerated site-nav.js with corrected paths

**Result:** Navigation now uses correct paths from all page locations.

## 🎯 Key Concepts

### File Processing Rules

**Processed by build:**
- ✅ menu.md → site-nav.js
- ✅ site.md → sitemap.xml + site-map.html
- ✅ site-helpers/md/*.md → HTML/*.html

**Never touched:**
- ❌ Hand-crafted HTML files (unless .md exists)
- ❌ site-helpers/md-bak/ (templates only)
- ❌ Dynamically generated (hns-pf.html)

### When to Use What

**Use Markdown (.md) for:**
- ✅ New content pages
- ✅ Frequently updated content
- ✅ Simple layouts
- ✅ Blog posts, documentation

**Keep as HTML for:**
- ✅ Existing complex pages
- ✅ Custom layouts
- ✅ Special features
- ✅ Dynamically generated pages
